# 生成式搜索监测工作台

内容团队希望知道，自己发布的文章进入 AI 搜索来源后，品牌是否更容易获得推荐。单看来源列表，很难判断一篇文章在最终回答中起了什么作用。

## 我怎样定义指标

<figure><figcaption>一次回答如何进入监测指标</figcaption><ol class="flow"><li>采集回答<small>记录题目、平台与轮次</small></li><li>保留证据<small>保存正文与可见来源</small></li><li>分别判定<small>来源命中、提及、推荐</small></li><li>汇总与回查<small>按链接统计，查看原答</small></li></ol></figure>

我把一次观察保留到回答级别。先看具体发布链接是否出现在已保存来源中，再看回答正文是否提及目标品牌，以及是否把它作为购买候选明确推荐。工作台支持从汇总数字回到原题、回答和对应链接。同一篇稿件投到不同渠道后，各链接分别统计。

| 自制示例 | 来源命中 | 正文提及品牌 A | 明确推荐品牌 A |
| --- | --- | --- | --- |
| 来源里出现目标文章，回答只介绍品牌 B | 是 | 否 | 否 |
| 来源里出现目标文章，回答只列出 A 的型号名称 | 是 | 是 | 否 |
| 来源里出现目标文章，回答说明某项需求下可以优先考虑 A | 是 | 是 | 是 |

## 从指标回到决策

如果文章频繁出现在来源中，正文却很少带出品牌，我会优先检查命中的题目、回答实际采用的理由和文章中的具体表述。比较不同链接时，需要同时看平台、题目和观察时间。来源面板未完整保存时，记录为未观察到链接。推荐判定尚未完成的回答单列，避免拉低推荐率。

工作台支持比较同一道题在观察到指定链接和未观察到链接时的推荐比例。两组的差异能筛出值得进一步研究的文章。要判断文章是否造成变化，还需要处理平台差异、同期发布和样本量等因素。
