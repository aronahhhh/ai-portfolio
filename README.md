# Aron · AI 应用作品集

我负责把业务问题做成可使用、可评估的 AI 工具。以下两个案例分别涉及职业教育知识检索，以及生成式搜索回答的持续监测。

## 项目案例

| 项目 | 我关注的问题 |
| --- | --- |
| [职业教育知识库](cases/knowledge.md) | 教学资料分散在文档和视频中，怎样让使用者拿到答案后还能找到对应的原文或片段？ |
| [生成式搜索监测工作台](cases/visibility.md) | 一篇文章出现在 AI 回答的来源里，品牌是否也获得了推荐？ |
